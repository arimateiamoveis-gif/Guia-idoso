📱 Guia do Celular

Aprenda de forma simples e segura.

⚠️ ATENÇÃO: Este site é um projeto de extensão universitária 100% gratuito. NUNCA solicitamos senhas, dados bancários ou pagamentos. Nosso único objetivo é orientar você!

🔍 1. Aumentar as letras

1. Abra a engrenagem ⚙️.
2. Toque em "Tela".
3. Toque em "Tamanho da fonte".
4. Arraste a bolinha para a direita.
💡 Faça isso primeiro. Vai facilitar todo o resto!

📹 2. Chamada de vídeo

1. Abra o WhatsApp.
2. Toque no nome da pessoa.
3. Toque no ícone de câmera.
4. Espere a pessoa atender.
🚨 Só faça chamada para números que você conhece.

🎤 3. Enviar áudio

1. Abra a conversa.
2. Segure o botão do microfone.
3. Fale sem pressa.
4. Solte o dedo para enviar.
💡 Se errou, deslize o dedo para o lado antes de soltar.

🚨 4. Golpe por ligação

Sinais: pedem senha, dizem que você ganhou prêmio.
🚨 Desligue. Ligue para o banco pelo número do verso do cartão.
💡 Banco nenhum liga pedindo senha. Nunca.

🔗 5. Golpe por link

Sinais: link estranho, "encomenda parada".
🚨 Não clique. Apague a mensagem.
💡 Melhor perder promoção do que perder dinheiro.

🚫 6. Bloquear número

1. Abra o WhatsApp.
2. Toque no número desconhecido.
3. Toque nos três pontinhos.
4. Toque em "Bloquear".
